# Gnos3 business modules — Cebuano (ceb-PH) glossary

Conventions:

- **Register**: polite, professional Cebuano as used in Philippine offices. Address the reader with the plural/polite *kamo / ninyo / inyo* ("Palihug pilia ang inyong kompanya"), never *ka / nimo* alone. Use *palihug* (please) in instructions and error messages, not in buttons.
- **Loanwords**: Philippine accountants work with English terms, so established accounting loanwords stay (account, journal, ledger, entry, invoice, VAT, trial balance, debit) inside Cebuano sentences. Cebuano verb affixes attach with a hyphen: *i-post*, *i-void*, *i-export*, *i-upload*, *gi-post*, *na-match*. Spanish-derived words take Cebuano spelling: *kompanya*, *kurensiya*, *balanse*, *resibo*, *petsa*, *kantidad*, *dokumento*, *kategorya*, *transaksiyon*.
- **Buttons**: short imperative (patient focus): *Tipigi*, *Papasa*, *Usba*, *Idugang*, *Kumpirmaha*; with a loan verb use *I-* (*I-post ang entry*, *I-export*). Nouns for headings and tabs (*Mga setting*, *Pagtugma sa bangko*).
- **Case and punctuation**: sentence case; English punctuation (colon and question mark without a space before), curly quotes “ ” around quoted UI labels; keep "e.g." as *pananglitan:* / *pan.*; DR / CR stay as written.
- **Plural**: *mga* before the noun (*mga account*, *mga invoice*); do not add an English -s to a loanword (*mga entry*, not *mga entries*).
- **Numbers and dates**: Philippine format, 1,234.56 (comma for thousands, point for decimals); dates follow the app's own format; month names come from the browser locale. Percentages stay as in the source (12%).
- **Taxes**: a `{{tax}}` / `{tax}` placeholder is a tax name (VAT, GST, Profits tax…); write *ang {{tax}}* so it reads for any of them.
- **Product names** never change: Gnos3, K4mi, SmartOffice, Finances, Ollama, Open WebUI, Excel, PDF, CSV.
