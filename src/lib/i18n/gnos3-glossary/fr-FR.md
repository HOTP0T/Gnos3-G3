# Gnos3 business modules — French (fr-FR) glossary

Conventions: "vous"; infinitive on buttons ("Enregistrer", "Créer l'écriture"); sentence case; a normal space before ":" "?" "!" (as in the Open WebUI French file); « » for quoted UI labels; "ex. :" for "e.g."; D / C for DR / CR; ALL-CAPS statement totals stay in capitals. Settings = "Réglages" (the app's existing word). A UI `{{tax}}` / books `{tax}` filled with VAT-type names is treated as feminine (la TVA); income-tax templates put the name first or in parentheses so they read for "Impôt sur les sociétés" too.
