# Gnos3 business modules — Estonian (et-EE) glossary

## Conventions

- **Form of address**: formal plural "Teie" forms in sentences and questions ("Kas soovite jätkata?", "Valige ettevõte", "Laadige fail üles"), as Open WebUI's Estonian file does. Pronoun "te/teie" lowercase inside sentences.
- **Buttons and menu items**: short imperative singular, as in Open WebUI ("Salvesta", "Kustuta", "Loo kanne", "Laadi üles", "Ekspordi"). Status words are past participles ("Kirjendatud", "Annulleeritud", "Sobitatud").
- **Case**: sentence case; only the first word and proper names capitalised. ALL-CAPS statement totals stay in capitals.
- **Punctuation**: Estonian quotation marks „…“ for quoted UI labels and names ( „{{name}}“ ). No space before ":" "?" "!". Ellipsis "…". "e.g." → "nt", "i.e." → "st", "etc." → "jne", "incl." → "sh", "approx." → "u".
- **Numbers and dates**: decimal comma (1 234,56), non-breaking space as thousands separator; dates dd.mm.yyyy; 24-hour time. Percent with a space: "20 %". Abbreviations: DR / CR → **D / K** (deebet / kreedit).
- **Placeholders**: Estonian is case-inflected; when a placeholder holds a noun that would need inflection, restructure the sentence so the placeholder stays in the nominative (e.g. "Konto: {{name}}", "{{tax}} (deklaratsioon)") or follow it with a noun in the right case ("ettevõttele {{name}}").
- **Product names** stay as they are: Gnos3, K4mi, SmartOffice, Ollama, Open WebUI, Excel, PDF, CSV, currency codes, units.
- **Two "confirm"-like verbs**: *Confirm* = "Kinnita"; *Approve* (expense sheets) = "Kiida heaks"; *Post* (ledger) = "Kirjenda"; *Void* = "Annulleeri" (never "Tühista", which is *Cancel*).
