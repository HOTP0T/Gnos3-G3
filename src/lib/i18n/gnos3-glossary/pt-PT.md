# Glossary: English → Português (Portugal), Gnos3 business modules

European Portuguese (AO90 spelling), SNC accounting terms. Buttons use the infinitive ("Guardar", "Criar lançamento") and sentence case. Instructions to the user use the formal imperative ("Selecione", "Adicione"). Progress messages use "A + infinitive" ("A guardar...").
